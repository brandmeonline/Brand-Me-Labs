# brandme-chain — Midnight rights adapter

Status and evidence: [`docs/build/status/opus-midnight-rights.md`](../docs/build/status/opus-midnight-rights.md).
Contract design and privacy statement: [`contracts/DESIGN.md`](contracts/DESIGN.md).

## What is here

| Path | What it is |
|---|---|
| `contracts/src/brandme_rights.compact` | Issuer registry, transferable entitlements and licensed reprint in one contract |
| `contracts/toolchain.json` | Pinned Midnight tuple (support matrix, 2026-10-05) and compiler asset sha256 |
| `contracts/managed/` | Compiled TS binding, zkir and verifier keys. Prover keys are regenerated by `pnpm compact:compile` |
| `contracts/artifact-manifest.json` | sha256 of every artifact (prover keys included). The adapter refuses mismatched material |
| `src/midnight/` | Real adapter on Midnight.js 4.1.1 provider boundaries: operations, private state + backup, network guard, capability |
| `src/cardano/anchor.ts` | Optional public anchor boundary. **Unverified and disabled**, never on the Midnight path |
| `tests/support/simulator.ts` | Test-only ledger simulator running the real compiled circuits |
| `tests/network/` | Live tests against a local Midnight network or Preprod, writing to `evidence/` |

There is no stub, simulation or fallback mode. Missing capability is reported by `GET /midnight/capability`, never faked.

## Commands

```bash
pnpm install                        # repo root; Node >= 22
pnpm --filter @brandme/chain test:midnight:local   # compile (pinned compactc), manifest check, all local suites

# Live local network (Docker): node 1.0.300 + indexer 4.3.5 + proof-server 8.1.0
bash scripts/local-network.sh up
export $(bash scripts/local-network.sh env)
pnpm test:midnight:network          # deploy → issue → prove → transfer → reprint → restore, writes evidence/*.json
bash scripts/local-network.sh down

# Preprod (requires 3 funded Preprod wallet seeds; the faucet requires a human captcha)
MN_PREPROD_SEEDS=<seed1>,<seed2>,<seed3> pnpm test:midnight:preprod
```

Mainnet writes are refused in this build (`assertWritable`); there is no override.
